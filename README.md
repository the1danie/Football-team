# ⚽ Football Team Duty Bot

Telegram-бот, который перед каждой игрой или тренировкой распределяет обязанности между игроками, подтвердившими участие: мячи, вода, манишки (кто забрал — тот и стирает).

- распределяет только между теми, кто нажал «✅ Буду»;
- мячи достаются только игрокам с машиной;
- в приоритете тот, кто выполнял эту обязанность реже и у кого меньше обязанностей в целом;
- если игрок передумал идти, его обязанность автоматически переходит другому;
- игроки могут меняться обязанностями;
- рассылает опрос «кто придёт» каждому в личку и напоминает тем, кто молчит;
- за неответ — минус: такие игроки получают обязанности первыми, пока не отработают;
- напоминания лично ответственным и в общий чат;
- статистика по команде и по каждому игроку.

## Как пользоваться

### Первый запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)) и пропишите его в `ADMIN_IDS`.
3. Запустите бота (см. ниже).
4. **Где сидит команда:**
   - **WhatsApp** — ничего настраивать не нужно. Бот не может писать в WhatsApp сам, поэтому всё, что
     должна увидеть команда, он присылает администратору готовым текстом с кнопкой
     **«📤 Отправить в WhatsApp»**: нажали → выбрали группу → отправили. Подробнее — ниже.
   - **Telegram-группа** — добавьте туда бота и отправьте **`/bindchat`**: игры, обязанности и
     напоминания бот будет публиковать в группу сам.
5. Каждый игрок один раз пишет боту в личку `/start`: имя бот берёт из профиля Telegram (если такое имя уже есть в команде — с фамилией) и спрашивает только, есть ли машина. Имя можно поменять в «👤 Мой профиль».
   Без этого бот не сможет присылать личные напоминания и предложения обмена.

### Приложение (Telegram Mini App)

Кнопка **«Открыть»** рядом с полем ввода в чате с ботом открывает приложение прямо внутри Telegram —
без установки и входа (Telegram сам сообщает, кто открыл, подпись проверяется на сервере).
Светлая и тёмная темы — как в Telegram.

- **Игры** — карточки игр: большие кнопки *Буду / Не знаю / Не буду*, срок ответа, кто идёт,
  обязанности («Твоя обязанность» сверху), **🔄 Поменяться** с выбором, на что меняешься.
- **Рейтинг** — лидерборд с пьедесталом 🥇🥈🥉: **🏆 Помощь** (выполненные обязанности),
  **⚽ Посещения** (сколько раз был), **⚠️ Минусы** (антирейтинг, неявки отдельно);
  за месяц или за всё время; нажмите на игрока — разбивка по обязанностям.
- **Профиль** — имя, машина, минусы и короткие правила.
- Для админа: **✏️ Изменить** в карточке игры — день, время, место, тип, минимум (отметившимся придёт
  сообщение об изменениях, напоминания пересчитаются, текст для WhatsApp — кнопкой);
  **＋ Новая игра** (день — лентой на 2 недели, время — сеткой 13:00–24:00, место —
  с подсказками), *Распределить / Пересчитать*, *✏️ Назначения*, *📤 В WhatsApp*, *Отменить*;
  вкладка **Игроки** — заявки, машина с закреплением, состав, имя, минусы, удаление.
- Новичок в приложении сразу проходит регистрацию (имя из Telegram + машина) и ждёт подтверждения.

Кнопку «Открыть» бот ставит сам (при первом вызове `/api/tick` или `/api/health`); кнопки
«📱 Открыть приложение» есть и в сообщениях бота. Всё по-прежнему можно делать и кнопками бота.
Приложение работает на Vercel (адрес `/app`); при локальном запуске без HTTPS-адреса его нет.

### Обязанности до и после тренировки

- **Сбор** — за 30 минут до начала («сбор в 22:30») в карточке, опросе, напоминаниях и тексте для WhatsApp (`GATHER_MINUTES`, 0 — не показывать).
- **Место в 2ГИС** — при создании игры можно вставить ссылку из 2ГИС («Поделиться» → «Скопировать ссылку»). Она запоминается для этого места, и потом подставляется сама. В карточке будет «📍 Место · открыть в 2ГИС», в Telegram название места станет ссылкой, а в тексте для WhatsApp появится строка «2ГИС: …». Если ссылки нет, бот откроет поиск по названию в городе `TWOGIS_CITY` (по умолчанию `petropavlovsk` — Петропавловск).
- **💧 Вода — до**: распределяется при закрытии сбора среди тех, кто придёт.
- **⚽ Мячи, 👕 Манишки — после** (кто забрал манишки, тот и стирает; отдельная «Стирка» выключена, её можно включить): через час после начала (`AFTER_DUTIES_MINUTES=60`),
  только среди тех, кто отметил «Буду». Задача — забрать домой и принести на следующую тренировку.
  Назначенным приходит сообщение, в Telegram-группу или админам для WhatsApp — кто что забирает.
- У кого уже есть обязанность «до» (вода), тому «после» достаётся, только если людей мало.
- Настройка у каждой обязанности — «до» или «после», нужна ли машина, вкл/выкл:
  приложение → Профиль → **⚙️ Обязанности** (или `/duties`, `/duty_phase <id>` в боте).

### Кто пришёл

- Через 15 минут после начала (`ATTENDANCE_ASK_MINUTES`) бот присылает админам список «Буду» с кнопками
  ✅/❌; то же — кнопка **«👥 Кто пришёл»** в карточке игры в приложении (доступна с часа до начала).
- **Отметил «Буду», но не пришёл** → минус (`NO_SHOW_POINTS=1`, игроку приходит сообщение), его обязанность
  «до» не засчитывается в статистику, обязанности «после» достаются тем, кто был (если уже получил — уходят другому).
- **Пришёл без отметки** → добавьте его в «пришли»: он станет «Буду» и попадёт в обязанности «после».
- Ошиблись — верните отметку, минус снимется.
- Кто ответил **«Не знаю»**, вместе с напоминанием молчащим получает «определись до …» (без минуса).

### Повторяющиеся тренировки и минимум игроков

- **Расписание** (приложение → Игры → 🔁 Расписание, или «Повторять каждую неделю» при создании):
  например, «каждый понедельник 20:00» и «каждую пятницу 20:00». Бот сам создаёт тренировку за
  N дней (по умолчанию 2), рассылает опрос и присылает админам анонс для WhatsApp. Расписание можно
  поставить на паузу, изменить день, время, место, минимум и срок опроса, удалить (созданные игры
  останутся). Перенос уже созданной тренировки не приводит к дублю.
- **Минимум игроков** — у игры или расписания. Если к закрытию сбора «Буду» меньше минимума, бот
  **ничего не отменяет сам**, а спрашивает админов: **✅ Провести всё равно / ⏳ Подождать ещё час /
  ❌ Отменить** (кнопки в сообщении и в карточке игры в приложении). «Подождать» — напомнит молчащим
  и «не знаю», админам даст текст для WhatsApp и через час спросит снова. Если пока ждали минимум
  набрался — игра состоится сама. Пока решения нет, обязанности не распределяются. Минусы молчавшим
  начисляются как обычно. Автоотмена без вопроса — `MIN_PLAYERS_AUTO_CANCEL=1`.

### Админы

- **Главный админ** — тот, чей Telegram ID в `ADMIN_IDS`. Его нельзя удалить или лишить прав из бота.
- Главный админ выдаёт права другим игрокам команды: «Игроки» → игрок → **«👑 Сделать админом»**
  (в приложении — переключатель «👑 Админ»). Новый админ получает сообщение и админское меню,
  может создавать игры, распределять обязанности, принимать игроков, получает заявки и тексты для WhatsApp.
- Выдавать и снимать права, а также удалять из команды других админов может только главный админ.

### Веб-версия (в браузере, без Telegram)

Если Mini App у кого-то не открывается или удобнее в Chrome/Safari:
1. В боте — **/web** (или Профиль → «🌐 Открыть в браузере»). Бот присылает **личную ссылку**
   `https://<проект>.vercel.app/app?key=…`.
2. Открыть её в браузере — тот же аккаунт и всё то же: игры, «Буду / Не буду», обязанности,
   статистика, у админа — управление. Браузер запоминает вход (ключ убирается из адресной строки),
   сайт можно добавить на главный экран. Тёмная тема — по настройкам устройства.
3. Ссылка подписана секретом бота (подделать нельзя), действует 180 дней. Если она попала не тому —
   в профиле **«Выйти везде»**: все старые ссылки перестают работать, новую выдаст /web.

Где игроки узнают про сайт: кнопка **«🌐 Сайт»** в меню бота, **«🌐 Открыть на сайте»** в каждом опросе
и в приветствии после подтверждения, плашка «Есть сайт — можно и без Telegram» на вкладке «Игры».
Для группы WhatsApp — готовая инструкция «как подключиться»: `/invite` или Профиль → «📤 Инструкция для команды».

Во всех текстах для WhatsApp две ссылки: **Telegram** (`t.me/бот?start=game_N`) и **Сайт**
(`/app?game=N` — общая, без ключа): кто уже входил на сайт, сразу попадает на эту игру.

Регистрация новых игроков — только через бота (/start), чтобы админ видел заявку.
Корень сайта `https://<проект>.vercel.app/` тоже открывает приложение (с подсказкой, как войти).

### Кто может пользоваться ботом

Посторонние в команду не попадают: кто нажал `/start`, тот попадает в «⏳ ждут подтверждения», а
администраторам приходит заявка с кнопками **✅ Принять / ⛔ Отклонить**. Пока заявку не приняли,
человек не может отмечаться, не получает опросы и не участвует в обязанностях. Когда админ принимает
игрока, тому приходит приветствие и открытые игры. Игроки, которые были в боте до появления
подтверждений, остаются в команде. Выключить подтверждение: `REQUIRE_APPROVAL=0`.

**🗂 Игроки** (или `/players`) — карточка каждого игрока:
- принять, отклонить, удалить из команды, вернуть (обязанности удалённого переходят другим);
- **🚗 машина** — админ ставит «есть / нет», и это **закрепляется**: игрок сам изменить уже не может
  (кнопка «🔓 Разрешить игроку менять машину» снимает закрепление). Если игрок меняет машину сам,
  пока она не закреплена, админам приходит уведомление;
- переименовать;
- временно убрать из состава (травма, уехал) — опросов и минусов нет.

| Кнопка | Что делает |

| ➕ Создать игру | дата → время (кнопки с 13:00 до 24:00 каждые полчаса или вручную) → игра/тренировка → место (необязательно) → публикация |
| 📅 Текущая игра | карточки ближайших игр с кнопками управления |
| 👥 Участники | кто будет / не будет / не знает, сколько машин |
| 🎯 Распределить обязанности | распределить вручную (или пересчитать заново) |
| ✏️ Изменить назначение | назначить конкретного игрока на обязанность или снять |
| ❌ Отменить игру | отмена с уведомлением в чат и ответственным |
| 📊 Статистика | сколько обязанностей у каждого |
| 🗂 Игроки | заявки новых игроков, машина, имя, состав, удаление |

Дополнительно: `/penalties` — минусы и их снятие, `/duties`, `/add_duty 🩹 Аптечка` (с машиной: `/add_duty 🎈 Насос машина`), `/toggle_duty <id>`.

### Игрок

- В чате команды под игрой: **✅ Буду / ❌ Не буду / 🤔 Пока не знаю**.
- После распределения в чате появляется сообщение с обязанностями и кнопкой **🔄 Поменяться** — она открывает личку с ботом: выбираешь участника, он получает предложение и может согласиться или отказаться. Можно предложить обязанность и тому, у кого её нет.
- **👤 Мой профиль** — сменить имя или наличие машины. Если убрать машину, твои «машинные» обязанности перейдут другим.

### Команда в WhatsApp

Telegram-группа не нужна. Каждый игрок один раз открывает бота в Telegram — дальше опросы, напоминания и
обязанности приходят ему в личку. В группу WhatsApp бот сам писать не может, поэтому присылает
администратору готовые тексты с кнопкой **«📤 Отправить в WhatsApp»** (откроет WhatsApp с текстом —
остаётся выбрать группу):

| Когда | Текст для WhatsApp |
|---|---|
| игра создана | анонс со ссылкой `t.me/бот?start=game_…` — по ней игрок сразу попадает на опрос (новичок — после выбора «есть ли машина») |
| за 3 ч до закрытия сбора | «⏰ Ещё не отметились: …» |
| закрытие сбора | кто получил минус; обязанности |
| за 2 ч до игры | «Сегодня игра в 20:00. Ответственные: …» |
| отмена | «❌ Игра отменена» |
| в любой момент | кнопка **«📤 Текст для WhatsApp»** в карточке игры (📅 Текущая игра) — кто идёт или обязанности |

Если кнопка не открылась (очень длинный текст) — зажмите сообщение и скопируйте его, он уже в нужном виде.
Эмодзи в текстах для WhatsApp не используются: по ссылке WhatsApp показывает их как «�».

### Опрос «кто придёт» и минусы

1. **Публикация игры** — кроме сообщения в чате, каждый игрок из состава получает в личку
   «📣 Открыт сбор на игру» с кнопками ✅ / ❌ / 🤔 и сроком, до которого нужно ответить.
2. **За 3 часа до закрытия сбора** (`RSVP_REMINDER_HOURS`) тем, кто не ответил, бот пишет лично,
   а в общий чат — «Ещё не отметились: …» с упоминаниями.
3. **Сбор закрывается** вместе с автораспределением (за 5 ч до начала; если оно выключено — за
   `PERSONAL_REMINDER_HOURS`). Кто так и не нажал ни одной кнопки — получает **−1** (`PENALTY_POINTS`).
   «🤔 Пока не знаю» — тоже ответ, минуса за него нет. Ручное распределение срок не сдвигает.
4. **Что дают минусы:**
   - пока у игрока есть минусы, обязанности достаются ему в первую очередь (`PENALTY_PRIORITY`);
   - каждая выполненная обязанность (игра прошла) списывает один минус;
   - на `PENALTY_LIMIT` (3) минусах и больше бот предупреждает игрока и администраторов —
     дальше решаете сами (штраф, скамейка);
   - кто получил минус, бот пишет в общий чат (`PENALTY_ANNOUNCE=0` — только лично);
   - минусы видны в «📊 Статистика» и в профиле игрока.
5. **Справедливость:** минус не получают те, кого админ убрал из состава (`/players`), кто пришёл в
   бота уже после публикации игры, и все — если игру создали меньше чем за час до закрытия сбора.
   Админ может снять минус в `/penalties` (уважительная причина).

### Автоматика

| Когда | Что | Настройка |
|---|---|---|
| при публикации | опрос в личку всем из состава | — |
| за 3 ч до закрытия сбора | напоминание молчащим — лично и в чат | `RSVP_REMINDER_HOURS` |
| за 5 ч до начала | сбор закрывается: минусы молчавшим, автоматическое распределение (отчёт — администраторам) | `AUTO_DISTRIBUTE_HOURS`, `0` — только вручную |
| за 3 ч | личное напоминание каждому ответственному | `PERSONAL_REMINDER_HOURS` |
| за 2 ч | напоминание в общий чат со списком ответственных | `GROUP_REMINDER_HOURS` |
| через 3 ч после начала | игра завершена, выполненные обязанности списывают минусы | `FINISH_AFTER_HOURS` |

Если игру создали позже момента автораспределения, бот распределит обязанности перед личным напоминанием, чтобы люди успели отметиться.
Если после распределения пришёл новый игрок, а какая-то обязанность осталась без исполнителя (например, не было никого с машиной), бот сразу назначит её ему.

## Алгоритм распределения

```
score = (сколько раз игрок выполнял эту обязанность) × 3
      + (сколько всего обязанностей у игрока)
      + 2, если у игрока была обязанность на прошлой игре
      − 10 × (минусы за неответы на опросы)
```

Чем меньше `score`, тем выше приоритет. Все обязанности игры распределяются за один проход
так, чтобы суммарный `score` был минимальным (задача о назначениях, венгерский алгоритм). Поэтому
последняя обязанность не достаётся по остаточному принципу тому, кто делал её в прошлый раз.
Две обязанности на одного человека бывают, только если участников меньше, чем обязанностей.
«Машинные» обязанности получают только игроки с машиной; если таких нет — бот предупреждает
и просит назначить вручную. Отменённые игры в статистике не учитываются.

Код алгоритма — `bot/services/distribution.py`, он не зависит от Telegram и БД.

## Запуск

Два режима, код один и тот же:

| | Vercel + Neon (бесплатно) | Сервер / Docker |
|---|---|---|
| Как бот получает сообщения | webhook: Telegram сам вызывает `/api/webhook` | polling: бот сам опрашивает Telegram |
| Напоминания и автораспределение | cron-job.org вызывает `/api/tick` раз в 5 минут | встроенный цикл раз в минуту |
| База | Neon (PostgreSQL) | PostgreSQL в Docker или SQLite |

### Vercel + Neon

**1. База в Neon.** На [neon.tech](https://neon.tech) создайте проект, регион — *AWS Europe Central 1 (Frankfurt)*,
рядом с функциями Vercel (`fra1` в `vercel.json`). Скопируйте строку подключения (Connection string),
вариант *Pooled connection* (с `-pooler` в адресе) — она подходит как есть:
`postgresql://…-pooler.eu-central-1.aws.neon.tech/neondb?sslmode=require&channel_binding=require`.

Можно и через Vercel: *Storage → Create Database → Neon* — тогда `DATABASE_URL` пропишется в проект сам.

**2. Проект в Vercel.** *Add New → Project*, импортируйте репозиторий с GitHub, Framework Preset — *Other*.
В *Environment Variables* добавьте:

| Переменная | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `ADMIN_IDS` | ваш Telegram ID (несколько — через запятую) |
| `DATABASE_URL` | строка подключения из Neon |
| `CRON_SECRET` | случайная строка, например результат `openssl rand -hex 32` |
| `TZ_NAME` | `Asia/Almaty` (или ваш часовой пояс) |

Нажмите *Deploy*. Если переменные добавляли после деплоя — *Deployments → ⋯ → Redeploy*.

**3. Планировщик — единственный ручной шаг.** Бесплатный cron в Vercel срабатывает раз в сутки
(он уже настроен в `vercel.json` как подстраховка), поэтому основной — [cron-job.org](https://cron-job.org)
(бесплатно): *Create cronjob* → URL `https://<ваш-проект>.vercel.app/api/tick?secret=<CRON_SECRET>`,
расписание — каждые 5 минут → *Create* → *Test run* (должно быть `{"ok": true, …}`).

Первый же вызов `/api/tick` сам подключит бота к Telegram (webhook) — открывать что-то ещё не нужно.
Хотите сразу — откройте `https://<ваш-проект>.vercel.app/api/health?secret=<CRON_SECRET>`: он тоже
подключит webhook и покажет, всё ли в порядке.

**4.** Напишите боту `/start` в личку. Если команда в Telegram-группе — добавьте туда бота и отправьте `/bindchat`;
если в WhatsApp — ничего больше не нужно.

**Если не работает** — откройте `https://<ваш-проект>.vercel.app/api/health?secret=<CRON_SECRET>`.
Бот проверит переменные, подключение к Neon и связь с Telegram, сам починит webhook и в поле `hints`
напишет, что исправить. Без `?secret` покажет только, какие переменные заданы.

`WEBHOOK_SECRET` задавать не нужно — бот выводит его из токена. Адрес бот берёт из основного домена
проекта (Vercel сообщает его сам); если используете свой домен — задайте `PUBLIC_URL`.

> Если позже переедете на сервер, `python -m bot` сам отключит webhook и перейдёт на polling.

### Docker (VPS)

```bash
cp .env.example .env   # впишите BOT_TOKEN и ADMIN_IDS
docker compose up -d --build
```

Поднимутся PostgreSQL и бот. Таблицы и стандартные обязанности создаются автоматически при старте.

### Локально (SQLite)

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env   # DATABASE_URL=sqlite+aiosqlite:///football.db
python -m bot
```

### Тесты

```bash
pytest
```

Тесты покрывают алгоритм, сервисный слой на реальной БД, сквозной сценарий через настоящий
диспетчер aiogram с фейковым Telegram API (регистрация → создание игры → отметки → распределение →
отказ → обмен → ручное назначение → статистика → напоминания → отмена) и адреса для Vercel.

По умолчанию тесты идут на SQLite. Прогон на PostgreSQL (база будет очищена):

```bash
TEST_DATABASE_URL="postgresql://user:pass@localhost:5432/test?sslmode=disable" pytest
```

## Структура

```
api/                  функции Vercel: webhook, tick, setup, health, app (страница), miniapp (API)
bot/
  __main__.py         запуск на сервере: python -m bot
  webhook.py          режим webhook (ASGI) для Vercel
  app.py              сборка бота и диспетчера для обоих режимов
  fsm_storage.py      состояния диалогов в БД
  operations.py       действия пользователей и админов — общие для бота и приложения
  miniapp_api.py      API приложения: проверка подписи Telegram, права, действия
  miniapp/index.html  интерфейс приложения
  config.py           настройки из переменных окружения
  models.py           таблицы: users, games, game_participants, duties, assignments, swap_requests, penalties
  deadlines.py        сроки: закрытие сбора, напоминания, автораспределение
  services/
    distribution.py   алгоритм распределения (без БД)
    games.py          игры, участники, назначения, обмены, статистика
  handlers/           хендлеры Telegram: профиль, админка, чат, обмены, статистика
  notifier.py         отправка и обновление сообщений
  scheduler.py        автораспределение, напоминания, завершение игр (раз в минуту)
  texts.py, keyboards.py
tests/
```

## Ограничения MVP

- Одна команда на одного бота (один общий чат).
- Схема БД создаётся через `create_all`, новые колонки добавляются при старте простой миграцией;
  для сложных изменений схемы стоит подключить Alembic.
- На Vercel первый ответ после долгого простоя может занять 1–3 секунды: просыпаются функция и база Neon.
